Isolation Forest: Detect Anomalies by Isolating Them

Watch random partitions isolate unusual points more quickly than typical points in dense regions.

Isolation depth

Interpretation

—
Shorter path length suggests stronger anomaly evidence.

1. Start with the whole space
2. Make a random split
3. Split again within a smaller region
4. Isolate a single observation
